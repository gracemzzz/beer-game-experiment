# Context supplied to the agents

Each fresh participant received its assigned task/prompt plus the same project maintenance and environment instructions. Those shared instructions mentioned all three fictional time allowances and earlier strict-pilot completion counts. The agents were not blinded to the overall design; the assigned student prompt was not their entire context.

Public transcripts showed no access to another arm's decisions or reading, scoring keys, private state, or implementation source. Procedure reviews are attributed local/operator evidence, not provider authentication or human-student validation. The common public context and its hashes are retained in data/student_framing_v3/COMMON_PROJECT_CONTEXT.json.

Block6 was interrupted by an account usage limit. After the user instructed continuation, all three cases resumed in the same existing contexts, retaining accepted decisions and the same requested model/effort. No replacement case or synthetic answer was used. The administrative amendment, exact continuation messages and extra public-context exposures are retained with the records. The primary sample remains all ten assigned blocks.
